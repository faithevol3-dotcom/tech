About TechPulse

TechPulse is a learning project that explains technology to people who are curious but not technical. Every topic starts with a simple question and ends with something you can use.

The site is built with plain HTML and CSS, so it loads fast and works on any device.

What we believe

Clarity first

If an idea cannot be explained simply, we keep working on the explanation.

Honest about limits

Every technology has trade-offs. We say what they are.

Open to everyone

No account, no paywall and no tracking. Just read.

Tools used to build this site

Everything here is hand-written and kept in a GitHub repository.

  • HTML5 for the structure of each page
  • CSS3 in a single style.css file for layout and colour
  • SVG for the images, so they stay sharp at any size
  • Git and GitHub for version control
