# TechPulse
A three-page website that explains technology (AI, cloud, cybersecurity) in plain language.

Files: `index.html`, `about.html`, `contact.html`, `style.css`, `images/`.
Run: open `index.html` in a browser. No secrets are stored in this project.
# SEMANTIC HTML PROTOTYPE – IT WORLD

**1. Pages Created**

I created three connected web pages:
- Home page
- About page
- Contact page

**2. Navigation**

I created a navigation menu on every page to allow users to move easily between Home, About and Contact pages.

**3. Semantic HTML Elements Used**

I used the following semantic HTML elements:
- `<header>` to organise the top section.
- `<nav>` to provide website navigation.
- `<main>` to contain the main content.
- `<section>` to group related information.
- `<article>` to present independent content where appropriate.
- `<footer>` to organise the bottom section.

**4. Form**

The Contact page contains an HTML form that collects visitors' full names, email addresses, subjects and messages.

**5. Accessibility Decisions**

I made the following accessibility improvements:
- Added meaningful alternative text to images.
- Associated labels with their corresponding form fields.
- Used headings in a logical order.
- Used descriptive navigation links.
